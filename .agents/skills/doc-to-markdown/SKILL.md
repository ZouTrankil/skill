# 文档转 Markdown

需要读取或分析上述文档时，优先用 `markitdown` 转换，再按需分段读取；不要将二进制文件或大体积原始表格直接放入模型上下文。转换结果适合内容分析，不保证保留原始版式、公式、图片或全部结构；需要精确版面、表格或编辑时，结合原文件和对应专用工具核对。

1. 检查 `markitdown` 是否可用。未安装时按环境约定安装，例如 `uv tool install 'markitdown[all]'`；安装不可用时说明依赖缺失，并使用合适的现有工具处理。不同格式可能需要对应可选依赖。
2. 将原文件转换到任务专用临时目录，保留原文件：

   ```bash
   markitdown "<输入文件路径>" -o "<临时输出路径.md>"
   ```

3. 检查命令退出状态、输出是否非空和文本是否可读，并根据任务核对标题、表格、关键数字及可能缺失的内容；非空不代表完整。表格中原单元格含 `|` 时检查是否被正确转义，空值及公式也要对照原文件；图表和关系图的文本不等于图形关系。按需分段读取，回传摘要和关键数据时注明来源文件名及转换局限。ZIP 转换需核对实际处理的成员；不能假定所有内容均已成功提取。
4. 扫描版 PDF 或图片型文档输出为空、乱码或缺失时，标注需要 OCR 或版面解析（如 Docling、MinerU），使用可用工具进一步处理；无法处理时说明未覆盖范围，不编造内容。
5. 任务结束后清理本次生成的临时 Markdown；用户要求保留或作为正式交付物时，保存到指定位置。

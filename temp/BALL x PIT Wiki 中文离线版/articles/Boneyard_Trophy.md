八个完工奖金建筑之一, **贝尼亚德奖** 在玩家第一次完成比赛时，该蓝图会被授予 [骸骨墓园](The_BONExYARD.md) [![The BONExYARD.png](../assets/The_BONExYARD.png)](The_BONExYARD.md) (与其他建筑物不同的是，这个和其他奖杯蓝图不能被击败的非老板敌人的滴滴。这种奖杯给所有角色一个状态效果功率奖励，而不是建立升级,Each character that has cleared the base level on Normal will give the base amount trophy bonus, and each character completion of each base level Fast-Fast+9 tier as well as each New Game+-New Game+9 clear on each Normal and Fast-Fast+9 tier will grant an additional bonus at 1/10 the base amount, yielding a theoretical maximum bonus of 238 * base amount.然而，如果在PC上播放并激活Twitch扩展, [伪救世主](The_False_Messiah.md) [![The False Messiah.png](../assets/The_False_Messiah.png)](The_False_Messiah.md),该最高奖金将增加到249.9* 基奖金值。建造这栋大楼将带来Trophy的成就。

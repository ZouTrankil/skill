# 疯长（Overgrowth）

[![Overgrowth.png](../assets/Overgrowth.png)](../files/Overgrowth.png.md)

施加 1 层疯长。达到 3 / 3 / 2 层时消耗全部层数，对 3 × 3 格范围内的所有敌人造成 150–200 / 180–250 / 180–250 点伤害。

# 冰冻射线（Freeze Ray）

[![Freeze Ray.png](../assets/Freeze_Ray.png)](../files/Freeze_Ray.png.md)

命中敌人时发射冰冻射线，对路径上的所有敌人造成 20–50 / 25–65 / 25–65 点伤害，并有 10% 的概率冻结它们 10.0 / 10.0 / 13.0 秒。

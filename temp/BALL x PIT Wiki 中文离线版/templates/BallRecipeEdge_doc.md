# 模板 · 球谱页/doc（BallRecipeEdge/doc）

[原文与贡献者记录](https://ballxpit.wiki.gg/wiki/Template:BallRecipeEdge%2Fdoc) · [修订 4042](https://ballxpit.wiki.gg/index.php?oldid=4042) · [返回目录](../%E7%90%83%E6%AF%94%E4%BC%A6%E6%88%98%E8%AE%B0%20Wiki.md)

一个进化配方的一个槽中的一种替代成分。 在 [BallRecipeEdges](../data/BallRecipeEdges.md) 中储存一行， 并且不起作用。

#### 职位安排

**从未被手牵过** [模块:BallData](../site/Module_BallData.md) 从上
`ingredient_N_options` 参数 QQ[球数据](BallData.md)在同一页上，在同一页上。

自己打字可以创建第二个手写版本的食谱， 它已经存储了—— 这可能与上面的槽位不同。 编辑配方 {}}}[球数据](BallData.md)代替。

#### 参数参数

| 参数 | 意义意思意思意思 |
| --- | --- |
| `slot_index` | 1-4。 共享槽的行为 **替代物**;不同的槽为 **相配元素** 。 |
| `ingredient` | 另一个球的页面标题。 从来没有显示别名。 |

结果是该行存储的页面，所以没有 `result`
参数。

#### 它所生产的东西,

辐射光束为 *（Laser H或激光V）+（poison或单元格 / Poison or Cell）*,分为四行:

| 位置(\_E) | 成分成分成分 |
| --- | --- |
| 1 | 激光 （水平 / Horizontal） |
| 1 | 激光 （垂直 / Vertical） |
| 2 | 中毒 |
| 2 | 细胞 |

#### 为什么这里没有活生生的例子

此模板向 Cargo 撰写， 并且是生成而不是输入的。 在此输入它将会在 *标签: 球配方标签/doc* 上输入一个配方边缘。 要查看真实边缘， 请打开 [特别的: Cargo Tats/ BallRecibeEdges](../data/BallRecipeEdges.md) 。

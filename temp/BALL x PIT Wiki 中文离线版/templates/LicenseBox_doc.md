# 模板 · LicenseBox/文档（LicenseBox/doc）

[原文与贡献者记录](https://ballxpit.wiki.gg/wiki/Template:LicenseBox%2Fdoc) · [修订 310](https://ballxpit.wiki.gg/index.php?oldid=310) · [返回目录](../%E7%90%83%E6%AF%94%E4%BC%A6%E6%88%98%E8%AE%B0%20Wiki.md)

说明
:   此模板用于创建各种图片许可证模板所使用的框体。当前默认样式适用于浅色主题的维基。如果您的维基采用深色主题，而此模板相对于维基上的其他元素过于明亮，只需更改以下样式参数即可。

:   `background-color:` 这是背景的颜色，当前设置为： `#fefefe`
:   `border-color:` 这是边框的颜色，当前设置为： `#d6d6d6`
:   `color:` 这是文本的颜色，当前设置为： `#333`

语法
:   类型 `{{[LicenseBox](LicenseBox.md)|<text=License text>}}` 在图片信息页面上。

# 模板 · 许可盒/doc（LicenseBox/doc）

[原文与贡献者记录](https://ballxpit.wiki.gg/wiki/Template:LicenseBox%2Fdoc) · [修订 310](https://ballxpit.wiki.gg/index.php?oldid=310) · [返回目录](../%E7%90%83%E6%AF%94%E4%BC%A6%E6%88%98%E8%AE%B0%20Wiki.md)

描述
:   此模板用于创建各种图像许可模板所使用的框。默认的外观目前是针对光标维基的。如果您的 Wiki 有一个暗色主题， 而这个模板相对于您的 wiki 上的其他元素太亮， 只需更改以下样式参数 :

:   `background-color:` 这是背景的颜色， 目前设定为 : `#fefefe`
:   `border-color:` 这是边框的颜色， 目前设置为 : `#d6d6d6`
:   `color:` 这是文本的颜色， 目前设定为 : `#333`

语法
:   类型 `{{[LicenseBox](LicenseBox.md)|<text=License text>}}` 在图像信息页面上。

这是一个使用 [DRUID 信息框](https://support.wiki.gg/wiki/DRUID_infoboxes) 框架的示例角色信息框。你可以根据需要进行编辑、重命名或删除。

## 修改此模板

要了解 DRUID 的工作原理，请 **编辑此页面**！其中包含了一些注释，解释了如何制作信息框的各个部分。

## 可复制的代码，用于其他内容页面

如果您想使用此信息框创建页面，可以使用下面的代码片段。请注意，此代码仅适用于内容页面！！它与修改模板支持的内容无关。

```
{{Example character infobox
|title=
|image=

|Region=
|Element=

|Attack=
|HP=
|Armor=
|Attack Speed=
}}
```

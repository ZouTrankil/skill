货物表: `BallStatsByLevel`

|  |  |
| --- | --- |
| 一行为 | 一级一球 |
| 存储于 | [模板 · 球状（BallStat）](BallStat.md) — `{{BallStat\|1\|damage=…\|effect=…}}`在球文章上写了三次 |
| 由手写的 | `level`、 `damage`、 `effect` |
| 衍生， 从未打字 | 什么都没有 |
| 从来没有放在这里 | 一个球名 —— 你放上的文章是球。 跨级别总计和上限 (“ 最大 8堆叠 ” ) : 这些属于 `stat_combined_description` 日期上 [圆球（Balls）](../data/Balls.md). |
| 另见 | [圆球（Balls）](../data/Balls.md) |

# 模板 · 球状态/Cargo 申报（BallStat/CargoDeclare）

[原文与贡献者记录](https://ballxpit.wiki.gg/wiki/Template:BallStat%2FCargoDeclare) · [修订 4011](https://ballxpit.wiki.gg/index.php?oldid=4011) · [返回目录](../%E7%90%83%E6%AF%94%E4%BC%A6%E6%88%98%E8%AE%B0%20Wiki.md)

此模板定义了“BallStatsByLevel”表。[查看表格](../data/BallStatsByLevel.md)。

Cargo 表： `BallStatsByLevel`

|  |  |
| --- | --- |
| 一行是 | 一个等级一个球 |
| 存储于 | [模板 · 球状态（BallStat）](BallStat.md) — `{{BallStat\|1\|damage=…\|effect=…}}`，在圆球条目中调用三次 |
| 手动撰写 | `level`、 `damage`、 `effect` |
| 衍生，从未输入 | 没什么 |
| 请勿在此处放置 | 一个球的名称——你为其添加的冠词即为该球。跨层总数和上限（“最多8层”）：这些属于…… `stat_combined_description` 在 [圆球（Balls）](../data/Balls.md). |
| 另见 | [圆球（Balls）](../data/Balls.md) |

行不会重新填充。获得或失去此模板的页面仅在下次解析时才会更新——请将其置为无效编辑。更改 `#cargo_declare` above 需要管理员运行 *Special:CargoTables → 重新创建数据*.

# 模板 · 颜色/文件（Color/doc）

[原文与贡献者记录](https://ballxpit.wiki.gg/wiki/Template:Color%2Fdoc) · [修订 487](https://ballxpit.wiki.gg/index.php?oldid=487) · [返回目录](../%E7%90%83%E6%AF%94%E4%BC%A6%E6%88%98%E8%AE%B0%20Wiki.md)

此模板创建了一个小颜色splotch , 其背景颜色与普通文本颜色代码相邻， 可用于预览颜色。

#### 使用率

`{{[color](Color.md)|<color>}}`
何处 `<color>` 任何有效 [CSS 颜色颜色](https://developer.mozilla.org/en-US/docs/Web/CSS/color_value).

#### 实例实例实例

```
My favorite color is {{color|darkgreen}}

I think the current {{color|#6d8afb}} of links should be changed to a {{color|#6df4fb}}

RGB is cool too, you can do {{color|rgb(128,255,128)}}, or even transparency with {{color|rgba(128,255,128,0.5)}}.
```

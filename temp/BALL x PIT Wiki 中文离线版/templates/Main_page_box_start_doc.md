## 模板数据

在主页面创建一个用于使用的框。

模板参数 此模板更倾向于使用块格式来排列参数。

| 参数 |  | 说明 | 类型 | 状态 |
| --- | --- | --- | --- | --- |
| 标题 | `title` `1` | 这个盒子的标题。 示例欢迎来到维基！ | 内容 | 建议 |
| 职业 | `class` | 为包裹此箱子的物品添加额外的职业。 建议数值`centered-content` `has-floating-image`示例centered-content | 未知 | 可选 |
| 风格 | `style` | 在包裹此框的框中添加内联CSS样式。 示例text-align:center; | 字符串 | 可选 |

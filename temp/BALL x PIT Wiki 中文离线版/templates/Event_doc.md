## 说明

要使用此模板，请添加 {{[Event](Event.md)}} 模板并填写相应的字段。未填写的字段将不会出现在文章中。此信息框模板使用 [Fandom 的信息框语法](https://ballxpit.wiki.gg/wiki/W%3AHelp%3AInfobox?action=edit&redlink=1)。

## 语法

```
{{Event
 | title         =
 | image         = [e.g. "Example.jpg"]
 | imagecaption  =
 | performers  =
 | date          =
 | location      =
}}
```

```
 | location      = Everywhere
}}
```

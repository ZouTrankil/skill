此模板定义了表格“ 球” 。 [查看表格](../data/Balls.md) 。

货物表: `Balls`

|  |  |
| --- | --- |
| 一行为 | 球的一种类型 |
| 存储于 | [模板:BallData](BallData.md) - 每种球体一次 |
| 由手写的 | 以上所有的一切，加上 `ingredient_N_options` 储存到 [Ball 圆形](../data/BallRecipeEdges.md) 而不是在这里 |
| 衍生， 从未打字 | 本表无任何内容是从此表格中得出 |
| 从来没有放在这里 | 从不添加页面标题所属的显示别名( 光) `Foo` 页面位置 `Foo (Ball)`A级 `page_name` 列 - 使用内置 `_pageName`. |
| 另见 | [BallStatsBylevel](../data/BallStatsByLevel.md),[BallRecipeEdges](../data/BallRecipeEdges.md) (中文(简体) )。 |

各行不回填填。只当本模板在下一个解析时， 增减该模板的页面才会更新， 无效编辑它。 更改 `#cargo_declare` 上面的管理员需要运行 *特别:Cargo Tables + 重建数据*.

# 模板 · 球数据/Cargo 申报（BallData/CargoDeclare）

[原文与贡献者记录](https://ballxpit.wiki.gg/wiki/Template:BallData%2FCargoDeclare) · [修订 4057](https://ballxpit.wiki.gg/index.php?oldid=4057) · [返回目录](../%E7%90%83%E6%AF%94%E4%BC%A6%E6%88%98%E8%AE%B0%20Wiki.md)

此模板定义了“Balls”表。[查看表格](../data/Balls.md)。

Cargo 表： `Balls`

|  |  |
| --- | --- |
| 一行是 | 一种球 |
| 存储于 | [模板 · 球数据（BallData）](BallData.md) — 每种球类型各出现一次 |
| 手动撰写 | 以上所有内容，再加上 `ingredient_N_options` 参数，已存储其中 [圆球配方材料表（BallRecipeEdges）](../data/BallRecipeEdges.md) 而不是在这里 |
| 衍生，从未输入 | 此表中的内容均非衍生而来。 |
| 请勿在此处放置 | 切勿在页面标题所在的位置添加显示别名（空置 `Foo` 页面所在的位置 `Foo (Ball)`). A `page_name` 栏位 — 使用内置的 `_pageName`. |
| 另见 | [圆球分级数值表（BallStatsByLevel）](../data/BallStatsByLevel.md)、 [圆球配方材料表（BallRecipeEdges）](../data/BallRecipeEdges.md) |

行不会重新填充。获得或失去此模板的页面仅在下次解析时才会更新——请将其置为无效编辑。更改 `#cargo_declare` above 需要管理员运行 *Special:CargoTables → 重新创建数据*.

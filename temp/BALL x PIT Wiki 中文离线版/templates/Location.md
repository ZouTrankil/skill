#### 描述

要使用此模板， 请添加 {} {}位置模板并填入相应字段。 左空字段不会出现在文章中。 此信息框模板的使用 [方制信息箱语法](https://ballxpit.wiki.gg/wiki/W%3AHelp%3AInfobox?action=edit&redlink=1).

#### 语法

```
{{Location
 | title         =
 | image         = [e.g. "Example.jpg"]
 | imagecaption  =
 | map           = [e.g. "Example.jpg"]
 | mapcaption    =
 | type          =
 | level         =
 | location      =
 | inhabitants   =
}}
```

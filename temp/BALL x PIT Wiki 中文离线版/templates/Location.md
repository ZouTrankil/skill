## 说明

要使用此模板，请添加 {{Location}} 模板并填写相应的字段。空白的字段将不会出现在文章中。此信息框模板使用 [Fandom 的信息框语法](https://ballxpit.wiki.gg/wiki/W%3AHelp%3AInfobox?action=edit&redlink=1)。

## 语法

```
{{Location
 | title         =
 | image         = [e.g. "Example.jpg"]
 | imagecaption  =
 | map           = [e.g. "Example.jpg"]
 | mapcaption    =
 | type          =
 | level         =
 | location      =
 | inhabitants   =
}}
```

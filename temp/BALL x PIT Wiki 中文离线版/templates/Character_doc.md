#### 描述

要使用此模板， 请添加 {} {}[性格](Character.md)模板并填入相应字段。 左空字段不会出现在文章中。 此信息框模板的使用 [方制信息箱语法](https://ballxpit.wiki.gg/wiki/W%3AHelp%3AInfobox?action=edit&redlink=1).

#### 语法

```
{{Character
 | description  =
 | ball         =
 | unlocking    =
 | house        =
 | ability      =
}}
```

##### 能力

默认角色，没有特殊的游戏规律。

```
{{Character
 | name         = The Warrior
 | image        = The Warrior.png
 | description  = A wandering warrior.
 | ball         = Bleed
 | unlocking    = N/A (available at the start of the game)
 | ability      = The default character, no special gameplay quirks.
}}
```

**NOTE:** 名称和图像参数是完全可选的，将分别默认于页面名称和图像名称。

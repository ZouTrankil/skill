## 说明

要使用此模板，请添加 {{[角色](Character.md)}} 模板并填写相应的字段。未填写的字段将不会出现在文章中。此信息框模板使用 [Fandom 的信息框语法](https://ballxpit.wiki.gg/wiki/W%3AHelp%3AInfobox?action=edit&redlink=1)。

## 语法

```
{{Character
 | description  =
 | ball         =
 | unlocking    =
 | house        =
 | ability      =
}}
```

### 能力

默认角色，无特殊游戏特性。

```
{{Character
 | name         = The Warrior
 | image        = The Warrior.png
 | description  = A wandering warrior.
 | ball         = Bleed
 | unlocking    = N/A (available at the start of the game)
 | ability      = The default character, no special gameplay quirks.
}}
```

**注意：** 名称和图片参数完全是可选的，默认将使用页面名称和图片名称。

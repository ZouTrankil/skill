# 模板 · 锚/博士（Anchor/doc）

[原文与贡献者记录](https://ballxpit.wiki.gg/wiki/Template:Anchor%2Fdoc) · [修订 481](https://ballxpit.wiki.gg/index.php?oldid=481) · [返回目录](../%E7%90%83%E6%AF%94%E4%BC%A6%E6%88%98%E8%AE%B0%20Wiki.md)

#### 总结

此模板可用于将隐性锁定（引用点 / reference points） 插入一个页面， 供内部 wiki 链接使用。

#### 使用率

要创建自定义锁定，请使用 `{{Anchor|Anchor Name}}` 页面中的任意位置。

例如，如果您创建了锚 `{{Anchor|Example Anchor}}` 页面中 `[[Example]]`,您可以通过内部链接访问 `[[Example#Example Anchor]]`.

记住，您可以创建 [重定向](https://support.wiki.gg/wiki/Redirect) 您可以更容易地调用此模板， 例如使用 `{{a|Anchor Name}}`.

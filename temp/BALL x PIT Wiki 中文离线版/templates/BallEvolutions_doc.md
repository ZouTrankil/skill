# 模板 · 球演变/doc（BallEvolutions/doc）

[原文与贡献者记录](https://ballxpit.wiki.gg/wiki/Template:BallEvolutions%2Fdoc) · [修订 4176](https://ballxpit.wiki.gg/index.php?oldid=4176) · [返回目录](../%E7%90%83%E6%AF%94%E4%BC%A6%E6%88%98%E8%AE%B0%20Wiki.md)

其他 `== Evolutions ==` 一张圆球的桌子上: 每一个球都是配方的成分， 以及每个配方所需要的。

#### 职位安排

单球每件一次，在 `== Evolutions ==` 没有参数——文章是圆球。

```
== Evolutions ==
{{BallEvolutions}}
```

#### 示例

可选的第一个参数覆盖页面， 这是显示此模板的唯一方法， 除了一个球文章以外 :

```
{{BallEvolutions|Burn}}
```

烧是十个球的成分上面没有它们的名字

当没有食谱使用球时， 表格会被一条直线替换， 而不是让部分空空 :

```
{{BallEvolutions|Armageddon}}
```

覆盖维基语言的一半——69个进化球中的49个是其直线的终点, [小球](../articles/Baby_Ball.md)也是如此。

#### 列列出的

[BallRecipeEdges](../data/BallRecipeEdges.md),因此表格不能变色:新进化的球从 **its 自己的** 页面提供边缘，并在此出现，而不触动此文章。

每行显示食谱 **其他** 插槽，因为 QQ[组合](Combination.md)已将目前页面前置。 三个元件， 全部在 [灼烧](../articles/Burn.md):

| 食用权 | 调 |
| --- | --- |
| 烧灼+铁 | 一个共同编辑器 |
| Burn + (poison **或** 石头) | 双行，每条可选 |
| 烧灼+风+冻结+地震 | 一行，三条共信 |

# 模板 · 为/doc（For/doc）

[原文与贡献者记录](https://ballxpit.wiki.gg/wiki/Template:For%2Fdoc) · [修订 499](https://ballxpit.wiki.gg/index.php?oldid=499) · [返回目录](../%E7%90%83%E6%AF%94%E4%BC%A6%E6%88%98%E8%AE%B0%20Wiki.md)

该帽子模板意在用来显示与读者可能希望访问的专题有关的网页。

模板参数 此模板更倾向于参数的内嵌格式化。

| 参数 |  | 描述 | 类型 | 状态 |
| --- | --- | --- | --- | --- |
| 主题 | `1` | 以下各页涉及的主题如下。 示例更多信息 | 线线 | 需要 |
| 关联页 | `2` | 相关页面。 示例关联页 | 页面名称 | 需要 |
| 第二页第二页 | `3` | 与第二页相关的第二页，第二页，与第二页有关，第二页，第二页。 示例第二次相关连的第二页 | 页面名称 | 可选 |
| 第三页第三页 | `4` | 第三个相关页。 示例第三次相关连的第三页 | 页面名称 | 可选 |

#### 实例实例实例

| 《法典法典法典》 | 结果 |
| --- | --- |
| `{{For\|more information\|Special:WantedPages}}` | 详情见 [特别:](https://ballxpit.wiki.gg/wiki/Special:WantedPages). |
| `{{For\|more information\|Special:WantedPages\|Special:UncategorizedPages}}` | 详情见 [特别:](https://ballxpit.wiki.gg/wiki/Special:WantedPages) 及 [特别:未分类](https://ballxpit.wiki.gg/wiki/Special:UncategorizedPages). |
| `{{For\|more information\|Special:WantedPages\|Special:UncategorizedPages\|Special:UncategorizedCategories}}` | 详情见 [特别:](https://ballxpit.wiki.gg/wiki/Special:WantedPages)、 [特别:未分类](https://ballxpit.wiki.gg/wiki/Special:UncategorizedPages)和 [特别:未划分的类别](https://ballxpit.wiki.gg/wiki/Special:UncategorizedCategories). |
| `{{For\|more information\|Special:WantedPages{{!}}Page 1}}` （海关链接标签 / Custom link label） | 详情见 [第1页](https://ballxpit.wiki.gg/wiki/Special:WantedPages). |

#### 依赖性

此模板要正常工作， 您需要以下信息:

* 其他 `{{[Hatnote](Hatnote.md)}}` 基准模板。
* 其他 `.hatnote` 类，在 [MediaWiki:Common.css](../site/MediaWiki_Common.css.md).

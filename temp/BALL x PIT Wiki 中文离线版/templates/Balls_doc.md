# 模板 · 球/doc（Balls/doc）

[原文与贡献者记录](https://ballxpit.wiki.gg/wiki/Template:Balls%2Fdoc) · [修订 4175](https://ballxpit.wiki.gg/index.php?oldid=4175) · [返回目录](../%E7%90%83%E6%AF%94%E4%BC%A6%E6%88%98%E8%AE%B0%20Wiki.md)

球类导航框：游戏中所有球类物品，按种类分类，位于球类文章下方。

## 放置方式

每篇球类文章的最后一行，由页面生成器发出。无参数。

```
{{Balls}}
```

在主页面上，它也将该页面归类于 [类别：球](../categories/Balls.md)。

## 组队

| 组队 | 行数 |
| --- | --- |
| 基础圆球 | `ball_class = base` |
| 进化圆球 | `ball_class = evolved` |
| 其他 | `ball_class = baby` |

对下列对象进行三次查询： [圆球](../data/Balls.md) 表格，按顺序排列
`_pageName`. 添加到维基百科的球会按字母顺序出现在正确的分类和位置中，且不会被编辑——这是手动输入的列表所无法做到的：它列出了20种基础圆球，而游戏中实际上有21种，因此该列表从未更新过。 [肉身](../articles/Flesh.md).

## 示例

此模板仅*读取*Cargo 信息，因此在此展示是安全的——与{{[BallData](BallData.md)}}和{{[BallStat](BallStat.md)}}不同，后者会存储与此页面相关的行数据。

球导航箱:游戏中的每个球都按种类分组放在球的脚下

#### 职位安排

每条圆球文章的最后一行， 由页面生成器发布， 没有参数。

```
{{Balls}}
```

在主空格中，它也将页面在 [类别:球](../categories/Balls.md) 下存档。

#### 组群群

| 组组群 | 行数 |
| --- | --- |
| 基础圆球 | `ball_class = base` |
| 进化圆球 | `ball_class = evolved` |
| 其他 | `ball_class = baby` |

对下列对象进行三次查询： [圆球](../data/Balls.md) 表格，每个表格
`_pageName`。加入 Wiki 的球在右组中出现，在正确的位置，按字母顺序排列，没有编辑此页面，这是被替换的手动类型列表无法做到的:当游戏有21个时，它命名了20个基球，从未更新过 [肉类](../articles/Flesh.md).

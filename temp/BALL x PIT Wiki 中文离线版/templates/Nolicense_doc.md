# 模板 · 无许可证/文档（Nolicense/doc）

[原文与贡献者记录](https://ballxpit.wiki.gg/wiki/Template:Nolicense%2Fdoc) · [修订 210](https://ballxpit.wiki.gg/index.php?oldid=210) · [返回目录](../%E7%90%83%E6%AF%94%E4%BC%A6%E6%88%98%E8%AE%B0%20Wiki.md)

说明
:   此模板用于标记版权状态不明的图片。它会自动将这些图片归类到 [未注明来源的文件](../categories/Unattributed_files.md) 类别中，以便后续维护。

语法
:   类型 `{{[Nolicense](Nolicense.md)}}` 在图片信息页面上。

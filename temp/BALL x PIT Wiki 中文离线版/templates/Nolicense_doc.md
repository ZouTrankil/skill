# 模板 · 无许可证/文档（Nolicense/doc）

描述
:   此模板用于标记未知版权状态的图像。 它自动将图像添加到 [unnatribted 文件](../categories/Unattributed_files.md) 类别， 以便日后维护

语法
:   类型 `{{[Nolicense](Nolicense.md)}}` 在图像信息页面上。

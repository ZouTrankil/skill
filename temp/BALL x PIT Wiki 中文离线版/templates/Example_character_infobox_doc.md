你试图编辑 [模板：示例角色信息框](Example_character_infobox.md) 吗？如果是的话，你可能来错了地方——这是 **文档页面**，而不是模板本身。要编辑模板，请访问此处：[https://ballxpit.wiki.gg/wiki/Template:Example\_character\_infobox?action=edit](https://ballxpit.wiki.gg/wiki/Template%3AExample_character_infobox?action=edit)

这是一个使用 [DRUID 信息框](https://support.wiki.gg/wiki/DRUID_infoboxes) 框架的示例角色信息框。你可以根据需要进行编辑、重命名或删除。

## 修改此模板

要了解 DRUID 的工作原理，请 **编辑此页面**！其中包含了一些注释，解释了如何制作信息框的各个部分。

## 可复制的代码，用于其他内容页面

如果您想使用此信息框创建页面，可以使用下面的代码片段。请注意，此代码仅适用于内容页面！！它与修改模板支持的内容无关。

```
{{Example character infobox
|title=
|image=

|Region=
|Element=

|Attack=
|HP=
|Armor=
|Attack Speed=
}}
```

您正在试图编辑 [模板:示例字符信息框](Example_character_infobox.md)如果是这样，你可能在一个错误的地方 - 这是 **文件文件页**,而不是模板本身。要编辑模板，请到这里: [https://ballxpit.wiki.gg/wiki/Template:Example\_character\_infobox?action=edit](https://ballxpit.wiki.gg/wiki/Template%3AExample_character_infobox?action=edit)

这是使用 [DRUID 信息框](https://support.wiki.gg/wiki/DRUID_infoboxes) 框架的示例字符信息框。 您可以编辑它， 重命名它， 或者按需要删除它。

#### 修改此模板

查看 DRUID 是如何工作的， 请 **编辑此页**! 它有若干评论意见， 解释如何制作信息箱的不同部分。

#### 用于其他内容页面的可复制代码

如果您想要使用此信息框创建页面， 您可以使用下面的片段。 请理解， 此代码仅用于 CentTection Pages ! ! 此代码与更改模板支持的内容无关。

```
{{Example character infobox
|title=
|image=

|Region=
|Element=

|Attack=
|HP=
|Armor=
|Attack Speed=
}}
```
